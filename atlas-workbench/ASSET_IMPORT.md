# Reference-image ingestion protocol

The Atlas Workbench reference registry currently accepts local image previews and JSON metadata; it does not upload images to GitHub. The chat's image attachments are not automatically available to GitHub.

For a real asset ingest, preserve originals under a content-hash identifier, record SHA-256, original filename, dimensions, media type, source URL, attribution, license, capture date, epistemic status, and review state. Do not equate a filename with a source citation. Generate lightweight WebP thumbnails separately. Keep original image and derived metadata distinguishable. Use human review before scientific claims are promoted to validated knowledge.

The Time × Scale navigator should connect diagrams by explicit typed relations and source-backed measurements, not inferred coordinates from image pixels. Characteristic duration, lookback time, discovery date, and future projections are different temporal coordinates.

Status: protocol drafted; persistent hosted image storage, browser QA, and GitHub synchronization remain outstanding.
